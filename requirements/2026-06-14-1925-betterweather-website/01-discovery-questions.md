# Discovery Questions (Phase 2)

Alle 5 Fragen werden hier dokumentiert bevor die erste gestellt wird.

---

**Q1:** Soll die Website echte Wetterdaten von einer externen API (z.B. OpenWeatherMap) abrufen und diese dann transformieren – im Gegensatz zu komplett gefakten/statischen Daten?
[Default: Yes]

**Q2:** Soll der Nutzer seinen Standort eingeben oder suchen können (z.B. Stadtname), anstatt nur automatische GPS-Ortung zu nutzen?
[Default: Yes]

**Q3:** Soll die Website eine mehrtägige Vorhersage anzeigen (z.B. 5–7 Tage), nicht nur das aktuelle Wetter?
[Default: Yes]

**Q4:** Soll die Website auf Mobilgeräten gut nutzbar sein (responsive Design)?
[Default: Yes]

**Q5:** Soll die Transformation (schlechtes Wetter → gutes Wetter) für den Nutzer unsichtbar sein – d.h. die Seite sieht aus wie eine echte seriöse Wetterseite ohne Hinweis auf die Manipulation?
[Default: Yes]
