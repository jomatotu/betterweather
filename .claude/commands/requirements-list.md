# Requirements - List All

Read `requirements/index.md` and scan `requirements/` for all timestamped folders.

For each requirement folder, read `metadata.json` and display:

```
Requirements:

✅ COMPLETE  2025-01-27-1430-user-authentication
   "Add login and registration flow"
   
🔄 IN-PROGRESS  2025-01-28-0900-payment-integration  ← ACTIVE
   "Integrate Stripe payments" | Phase: Detail 3/5
   
⚠️  INCOMPLETE  2025-01-25-1100-dashboard-redesign
   "Redesign the main dashboard"
```

Then offer:
- Type a requirement name to view its spec
- /requirements-start to begin a new one
- /requirements-status to continue the active one
